# SOPEX Advisory

Responsive static website based on the supplied Website PDF. Uses the four-color palette, supplied service and About content, and diagnostic scope and pricing. Navigation uses hash routes so deployment works on any static host without rewrite rules. Insights and the resource worksheet are original editorial drafts based on the brief; review before publishing.

## Development

Node.js 22+; no dependencies or installation required.

- `npm run dev` — serves the site on port 3000 (override with `PORT`).
- `npm run check` — JavaScript syntax validation.
- `npm run build` — copies the deployable site into `dist/`.

Use the existing checkout; no Git worktree is needed.

## Before public launch

Supply and verify the business contact address, identity details, and contact delivery service. Currently the inquiry form explicitly downloads a local text file and sends nothing. Update the privacy notice once hosting and delivery details are confirmed. No analytics or third-party scripts are included.

The diagrams are original CSS artwork. No portrait from the reference mockups is represented as an authentic photo. Review all copy and obtain an approved portrait if desired. Deployment and domain configuration are not included.
